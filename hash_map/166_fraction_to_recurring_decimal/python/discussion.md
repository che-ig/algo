Это классическая задача на **деление в столбик** с отслеживанием остатков через хешмап. Ключевая идея: если остаток повторяется, значит начинается периодическая часть.

## Оптимальное решение

```python
class Solution:
    def fractionToDecimal(self, numerator, denominator):
        # Обработка нуля
        if numerator == 0:
            return "0"

        result = []

        # 1. Определяем знак результата
        # XOR знаков: если ровно один из них отрицательный — результат отрицательный
        if (numerator < 0) ^ (denominator < 0):
            result.append("-")

        # 2. Работаем с абсолютными значениями
        # В Python нет проблемы переполнения, но логически правильно
        num = abs(numerator)
        den = abs(denominator)

        # 3. Целая часть
        result.append(str(num // den))
        remainder = num % den

        # Если остаток 0 — дробь конечная, возвращаем результат
        if remainder == 0:
            return "".join(result)

        # 4. Дробная часть
        result.append(".")

        # Словарь: остаток → позиция в result, где будет записана цифра
        # Это нужно, чтобы знать, куда вставить открывающую скобку '('
        remainder_map = {}

        while remainder != 0:
            # Если такой остаток уже встречался — нашли период!
            if remainder in remainder_map:
                # Вставляем '(' на позицию, где началась периодическая часть
                result.insert(remainder_map[remainder], "(")
                result.append(")")
                break

            # Запоминаем позицию текущего остатка
            remainder_map[remainder] = len(result)

            # Деление в столбик: умножаем остаток на 10
            remainder *= 10

            # Добавляем очередную цифру дробной части
            result.append(str(remainder // den))

            # Обновляем остаток
            remainder %= den

        return "".join(result)
```

## Разбор на примере `numerator = 4, denominator = 333`:

**Шаг 1-3:** Целая часть

- `4 // 333 = 0`, остаток `4`
- `result = ["0", "."]`

**Шаг 4:** Дробная часть (деление в столбик)

| Шаг | remainder | remainder_map           | Цифра | Новый остаток | result                      |
| --- | --------- | ----------------------- | ----- | ------------- | --------------------------- |
| 1   | 4         | `{4: 2}`                | 0     | 40            | `["0", ".", "0"]`           |
| 2   | 40        | `{4: 2, 40: 3}`         | 1     | 67            | `["0", ".", "0", "1"]`      |
| 3   | 67        | `{4: 2, 40: 3, 67: 4}`  | 2     | **4**         | `["0", ".", "0", "1", "2"]` |
| 4   | **4**     | Уже в map на позиции 2! | -     | -             | Вставляем `(` на позицию 2  |

После вставки скобок: `["0", ".", "(", "0", "1", "2", ")"]` → `"0.(012)"` ✓

## Разбор на примере `numerator = 1, denominator = 2`:

- Целая часть: `1 // 2 = 0`, остаток `1`
- `result = ["0", "."]`
- Дробная часть:
  - `remainder = 1`, цифра `10 // 2 = 5`, остаток `0`
  - `result = ["0", ".", "5"]`
- Остаток стал 0 → цикл завершается
- Результат: `"0.5"` ✓

## Разбор на примере `numerator = 2, denominator = 1`:

- Целая часть: `2 // 1 = 2`, остаток `0`
- Остаток == 0 → сразу возвращаем `"2"` ✓

## Особый случай: отрицательные числа

**Пример: `numerator = -1, denominator = 2`**

- `(numerator < 0) ^ (denominator < 0)` → `True ^ False` → `True`
- Добавляем `"-"` в начало
- Работаем с `abs(-1) = 1`, `abs(2) = 2`
- Результат: `"-0.5"` ✓

**Пример: `numerator = -50, denominator = 8`**

- Знак: отрицательный
- Целая часть: `50 // 8 = 6`, остаток `2`
- Дробная: `20 // 8 = 2`, остаток `4`; `40 // 8 = 5`, остаток `0`
- Результат: `"-6.25"` ✓

## Почему это работает?

При делении в столбик:

- Каждый остаток **строго меньше** знаменателя
- Значит, возможных остатков **конечное число** (от 0 до `den-1`)
- Если остаток повторился — процесс деления зацикливается, и мы получаем **период**
- Если остаток стал 0 — дробь **конечная**

Это гарантирует, что цикл либо завершится (конечная дробь), либо найдёт повтор (периодическая дробь).

## Сложность:

- **Время:** $\mathcal{O}(d)$, где $d$ — знаменатель (максимум $d$ уникальных остатков)
- **Память:** $\mathcal{O}(d)$ для словаря остатков

По условию длина ответа ≤ $10^4$, поэтому алгоритм работает эффективно для всех тестов.

# Подробное объяснение решения

## 1. Математическая основа: деление в столбик

Когда мы делим числа вручную (в столбик), мы выполняем следующие шаги:

```
    0.012...
   _______
333)4.0000
    0
    ---
    40      ← 4 * 10 = 40
     0      ← 40 // 333 = 0
    ---
    400     ← 40 * 10 = 400
    333     ← 400 // 333 = 1, остаток 400 - 333 = 67
    ---
     670    ← 67 * 10 = 670
     666    ← 670 // 333 = 2, остаток 670 - 666 = 4
      ---
        4   ← ОСТАТОК ПОВТОРИЛСЯ! (был в начале)
```

**Ключевой момент:** каждый шаг деления зависит **только от текущего остатка**. Если остаток повторяется, то и все последующие шаги будут идентичны — это и есть **период**.

## 2. Почему повтор остатка = период?

Представьте, что вы робот, который выполняет деление. У вас есть только одно "входное данные" — **остаток**. Если вы получаете тот же остаток, что и раньше, вы сделаете **те же самые действия** и получите **те же самые цифры**.

### Формальное доказательство:

Пусть на шаге `i` остаток равен `r`. Тогда:

- Цифра на этом шаге: `d_i = (r * 10) // den`
- Следующий остаток: `r_{i+1} = (r * 10) % den`

Если на шаге `j` (где `j > i`) остаток снова равен `r`, то:

- `d_j = (r * 10) // den = d_i` ← **та же цифра**
- `r_{j+1} = (r * 10) % den = r_{i+1}` ← **тот же следующий остаток**

Значит, последовательность цифр `d_i, d_{i+1}, ..., d_{j-1}` будет повторяться бесконечно.

## 3. Пошаговый разбор с визуализацией

### Пример: `4 / 333`

**Шаг 0:** Целая часть

```
4 ÷ 333 = 0 (целая часть)
остаток = 4
```

`result = ["0", "."]`

**Шаг 1:** Первый остаток `r = 4`

```
4 * 10 = 40
40 ÷ 333 = 0 (цифра)
остаток = 40 % 333 = 40
```

Запоминаем: `remainder_map = {4: 2}` (позиция 2 в result)
`result = ["0", ".", "0"]`

**Шаг 2:** Остаток `r = 40`

```
40 * 10 = 400
400 ÷ 333 = 1 (цифра)
остаток = 400 % 333 = 67
```

Запоминаем: `remainder_map = {4: 2, 40: 3}`
`result = ["0", ".", "0", "1"]`

**Шаг 3:** Остаток `r = 67`

```
67 * 10 = 670
670 ÷ 333 = 2 (цифра)
остаток = 670 % 333 = 4
```

Запоминаем: `remainder_map = {4: 2, 40: 3, 67: 4}`
`result = ["0", ".", "0", "1", "2"]`

**Шаг 4:** Остаток `r = 4`

```
4 уже есть в remainder_map на позиции 2!
Значит, период начинается с позиции 2.
```

Вставляем `(` на позицию 2 и добавляем `)` в конец:

```
result = ["0", ".", "(", "0", "1", "2", ")"]
         [0]   [1]  [2]  [3]  [4]  [5]  [6]
```

Результат: `"0.(012)"` ✓

## 4. Механика вставки скобок

### Как работает `result.insert(pos, "(")`?

Метод `insert(pos, value)` вставляет элемент на позицию `pos`, сдвигая все последующие элементы вправо.

**До вставки:**

```
result = ["0", ".", "0", "1", "2"]
          0    1    2    3    4
```

**После `result.insert(2, "(")`:**

```
result = ["0", ".", "(", "0", "1", "2"]
          0    1    2    3    4    5
```

**После `result.append(")")`:**

```
result = ["0", ".", "(", "0", "1", "2", ")"]
          0    1    2    3    4    5    6
```

### Почему позиция `2`?

Потому что `remainder_map[4] = 2` — это позиция, где была записана **первая цифра**, полученная из остатка `4`. Все цифры начиная с этой позиции образуют период.

## 5. Почему гарантированно найдём повтор или остаток станет 0?

### Теорема о конечном числе остатков:

При делении на `den` возможные остатки: `0, 1, 2, ..., den-1`.

Это **конечное множество** из `den` элементов. По принципу Дирихле (принцип голубей и ящиков):

- Если мы делаем больше `den` шагов, хотя бы один остаток **обязан** повториться
- Как только остаток повторяется — начинается период

### Два возможных сценария:

**Сценарий 1:** Остаток становится `0`

- Дробь **конечная** (например, `1/2 = 0.5`)
- Цикл завершается, скобки не нужны

**Сценарий 2:** Остаток повторяется

- Дробь **периодическая** (например, `1/3 = 0.(3)`)
- Находим позицию первого вхождения остатка и вставляем скобки

## 6. Почему XOR для знака?

```python
if (numerator < 0) ^ (denominator < 0):
    result.append("-")
```

**XOR (исключающее ИЛИ)** возвращает `True`, если **ровно один** операнд `True`.

| numerator | denominator | XOR     | Результат |
| --------- | ----------- | ------- | --------- |
| `+`       | `+`         | `False` | `+`       |
| `+`       | `-`         | `True`  | `-`       |
| `-`       | `+`         | `True`  | `-`       |
| `-`       | `-`         | `False` | `+`       |

Это элегантный способ определить знак без множества `if-else`.

## 7. Почему `abs()` для числителя и знаменателя?

После определения знака мы работаем только с **положительными** числами. Это упрощает логику:

- Не нужно беспокоиться о знаке при делении
- Остатки всегда положительные
- Словарь остатков работает корректно

## 8. Пример с отрицательными числами

### `numerator = -1, denominator = 2`

**Шаг 1:** Знак

```
(-1 < 0) ^ (2 < 0) → True ^ False → True
result = ["-"]
```

**Шаг 2:** Абсолютные значения

```
num = abs(-1) = 1
den = abs(2) = 2
```

**Шаг 3:** Целая часть

```
1 // 2 = 0, остаток 1
result = ["-", "0", "."]
```

**Шаг 4:** Дробная часть

```
remainder = 1
1 * 10 = 10
10 // 2 = 5, остаток 0
result = ["-", "0", ".", "5"]
```

Остаток `0` → цикл завершается.

Результат: `"-0.5"` ✓

## 9. Сложность и гарантии

### Почему длина ответа ≤ 10⁴?

Максимальная длина периода = `den - 1` (так как возможных остатков `den`).

По условию `denominator ≤ 2³¹ - 1`, но гарантируется, что длина ответа ≤ 10⁴. Это значит, что для всех тестовых случаев период достаточно короткий.

### Сложность:

- **Время:** $\mathcal{O}(d)$, где $d$ — длина периода (или количество шагов до остатка 0)
- **Память:** $\mathcal{O}(d)$ для словаря остатков и списка `result`

## 10. Итоговая интуиция

1. **Деление в столбик** — это процесс, где каждый шаг зависит только от остатка
2. **Повтор остатка** = начало периода (все последующие шаги идентичны)
3. **Хешмап** запоминает, на какой позиции был каждый остаток
4. **Вставка скобок** отмечает начало и конец периода
5. **Остаток 0** = конечная дробь, скобки не нужны

Это решение элегантно использует математическое свойство деления и хешмап для отслеживания состояния процесса.

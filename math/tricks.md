# Математические трюки с остатками: Полное руководство

Да, таких трюков **очень много**, и они являются одним из самых мощных инструментов в арсенале алгоритмиста. Эти приемы основаны на **модулярной арифметике** и позволяют сводить сложные задачи к простым проверкам.

## Топ-10 трюков с остатками

### 1. **Разность кратна k → одинаковые остатки** (тот, что мы использовали)

```
a - b ≡ 0 (mod k) ⟺ a ≡ b (mod k)
```

**Применение:**

- **523. Continuous Subarray Sum** — подмассив с суммой, кратной k
- **974. Subarray Sums Divisible by K** — количество подмассивов с суммой, кратной k
- **1010. Pairs of Songs With Total Durations Divisible by 60** — пары с суммой, кратной 60

**Пример задачи:**

```python
# Найти количество подмассивов с суммой, кратной k
def subarraysDivByK(nums, k):
    count = {0: 1}  # остаток → частота
    prefix_sum = 0
    result = 0

    for num in nums:
        prefix_sum = (prefix_sum + num) % k
        if prefix_sum in count:
            result += count[prefix_sum]
            count[prefix_sum] += 1
        else:
            count[prefix_sum] = 1

    return result
```

### 2. **Сумма кратна k → остатки в сумме дают k или 0**

```
a + b ≡ 0 (mod k) ⟺ (a % k) + (b % k) == k или 0
```

**Применение:**

- **1. Two Sum** (модификация) — найти пару с суммой, кратной k
- **1679. Max Number of K-Sum Pairs** — максимум пар с суммой k
- **1010. Pairs of Songs With Total Durations Divisible by 60**

**Пример:**

```python
# Найти пары с суммой, кратной k
def pairsDivisibleByK(nums, k):
    remainder_count = {}
    result = 0

    for num in nums:
        rem = num % k
        complement = (k - rem) % k  # (k - rem) для rem > 0, 0 для rem == 0

        if complement in remainder_count:
            result += remainder_count[complement]

        remainder_count[rem] = remainder_count.get(rem, 0) + 1

    return result
```

### 3. **Делимость на 2, 5, 10 → смотрим только на последнюю цифру**

```
n % 2 == n % 10 % 2
n % 5 == n % 10 % 5
n % 10 == n % 10
```

**Применение:**

- **1323. Maximum 69 Number** — заменить одну 6 на 9
- **202. Happy Number** (оптимизация)
- Задачи на проверку четности/нечетности

### 4. **Делимость на 3, 9 → сумма цифр**

```
n % 3 == sum_of_digits(n) % 3
n % 9 == sum_of_digits(n) % 9
```

**Применение:**

- **1295. Find Numbers with Even Number of Digits** (косвенно)
- Задачи на проверку делимости больших чисел

**Пример:**

```python
def isDivisibleBy9(n):
    digit_sum = sum(int(d) for d in str(n))
    return digit_sum % 9 == 0
```

### 7. **Степени числа по модулю → цикличность**

```
a^n % m имеет период (цикл)
```

**Применение:**

- **372. Super Pow** — `(a^b) % 1337`
- **1337. The k-th Factor of n** (косвенно)

**Пример:**

```python
# Вычислить (a^b) % m эффективно
def power(a, b, m):
    result = 1
    a = a % m
    while b > 0:
        if b % 2 == 1:
            result = (result * a) % m
        a = (a * a) % m
        b //= 2
    return result
```

### 8. **Китайская теорема об остатках (CRT)**

Если `m1, m2, ..., mk` попарно взаимно просты, то система:

```
x ≡ a1 (mod m1)
x ≡ a2 (mod m2)
...
x ≡ ak (mod mk)
```

имеет **единственное** решение по модулю `M = m1 * m2 * ... * mk`.

**Применение:**

- **1590. Make Sum Divisible by P** (косвенно)
- Олимпиадные задачи

---

### 9. **Малая теорема Ферма**

Если `p` — простое и `gcd(a, p) == 1`, то:

```
a^(p-1) ≡ 1 (mod p)
```

Следствие: `a^(p-2) ≡ a^(-1) (mod p)` (модульное обратное)

**Применение:**

- **1642. Furthest Building You Can Reach** (косвенно)
- Задачи на модульную арифметику с делением

---

### 10. **Остатки при делении на степени 2 → битовые операции**

```
n % (2^k) == n & ((1 << k) - 1)
```

**Применение:**

- **191. Number of 1 Bits**
- **338. Counting Bits**
- Все задачи на битовые маски

**Пример:**

```python
# n % 8 == n & 7
n = 29  # 11101 в двоичной
print(n % 8)      # 5
print(n & 7)      # 5 (101 в двоичной)
```

## Как распознать, что нужен трюк с остатками?

### 🔑 Ключевые слова в условии:

1. **"кратный" / "делится на" / "divisible by"**
2. **"остаток" / "remainder"**
3. **"по модулю" / "modulo"**
4. **"сумма делится на k"**
5. **"разность делится на k"**

### 🎯 Типичные признаки:

- Нужно найти подмассив/подпоследовательность с суммой, кратной k
- Нужно найти пары с суммой/разностью, кратной k
- Большие числа, но нужно проверить делимость
- Задачи на цикличность (дни недели, часы)

### 🚩 Когда НЕ использовать:

- k = 1 (всё делится на 1)
- k очень большое (больше суммы всех элементов)
- Задача на поиск пути в графе (не связано)

## Практические советы

### 1. **Всегда используйте модуль при сложении/умножении**

```python
# ❌ Плохо (может быть переполнение)
result = (a + b) % m

# ✅ Хорошо (если a и b уже < m)
result = (a + b) % m

# ✅ Еще лучше (для умножения)
result = ((a % m) * (b % m)) % m
```

### 2. **Для отрицательных чисел в Python**

```python
# Python: -5 % 3 == 1 (всегда положительный остаток)
# C++/Java: -5 % 3 == -2 (может быть отрицательным)

# Если нужен положительный остаток в C++/Java:
int rem = ((a % m) + m) % m;
```

### 3. **Используйте словари для подсчета остатков**

```python
from collections import defaultdict

remainder_count = defaultdict(int)
for num in nums:
    remainder_count[num % k] += 1
```

# Символ `≡` (Конгруэнтность / Сравнение по модулю)

Символ `≡` (три горизонтальные черты) означает **"конгруэнтно"** или **"сравнимо по модулю"**. Это специальный математический символ, который отличается от обычного равенства `=`.

## Как читается выражение

```
a ≡ b (mod k)
```

Читается как: **"a сравнимо с b по модулю k"** или **"a конгруэнтно b по модулю k"**

Это означает: **a и b дают одинаковый остаток при делении на k**.

## Формальное определение

```
a ≡ b (mod k)  ⟺  k делит (a - b)  ⟺  a % k == b % k
```

То есть три эквивалентные формулировки:

1. `a` сравнимо с `b` по модулю `k`
2. Разность `(a - b)` делится на `k` без остатка
3. `a` и `b` дают одинаковый остаток при делении на `k`

## Примеры

### Пример 1: `17 ≡ 5 (mod 6)`

- `17 % 6 = 5`
- `5 % 6 = 5`
- Остатки равны → **верно** ✓
- Проверка: `17 - 5 = 12`, и `12` делится на `6` ✓

### Пример 2: `23 ≡ 3 (mod 10)`

- `23 % 10 = 3`
- `3 % 10 = 3`
- Остатки равны → **верно** ✓
- Проверка: `23 - 3 = 20`, и `20` делится на `10` ✓

### Пример 3: `15 ≡ 8 (mod 4)`

- `15 % 4 = 3`
- `8 % 4 = 0`
- Остатки разные → **неверно** ✗
- Проверка: `15 - 8 = 7`, и `7` не делится на `4` ✗

## Чем отличается от обычного `=`?

| Символ | Название       | Пример           | Значение                                               |
| ------ | -------------- | ---------------- | ------------------------------------------------------ |
| `=`    | Равенство      | `5 = 5`          | Числа **идентичны**                                    |
| `≡`    | Конгруэнтность | `17 ≡ 5 (mod 6)` | Числа **равны по модулю**, но не обязательно идентичны |

### Важное отличие:

```
17 = 5        ← НЕВЕРНО (17 не равно 5)
17 ≡ 5 (mod 6) ← ВЕРНО (оба дают остаток 5 при делении на 6)
```

## Разбор вашего выражения

```
a - b ≡ 0 (mod k)  ⟺  a ≡ b (mod k)
```

Это утверждение говорит:

**"Разность `a - b` сравнима с 0 по модулю k тогда и только тогда, когда `a` сравнимо с `b` по модулю k"**

### Что это означает на практике:

**Левая часть:** `a - b ≡ 0 (mod k)`

- Разность `(a - b)` дает остаток 0 при делении на k
- То есть `(a - b)` делится на k без остатка
- То есть `(a - b)` кратно k

**Правая часть:** `a ≡ b (mod k)`

- `a` и `b` дают одинаковый остаток при делении на k

**Символ `⟺`** означает **"тогда и только тогда"** (эквивалентность). Это значит, что оба утверждения **равносильны** — если верно одно, автоматически верно другое.

### Пример:

Пусть `a = 17`, `b = 5`, `k = 6`:

**Проверяем левую часть:**

- `a - b = 17 - 5 = 12`
- `12 ≡ 0 (mod 6)` → `12 % 6 = 0` ✓ ВЕРНО

**Проверяем правую часть:**

- `17 ≡ 5 (mod 6)` → `17 % 6 = 5` и `5 % 6 = 5` ✓ ВЕРНО

Обе части верны → эквивалентность подтверждена ✓

## Где это используется в программировании?

В Python это записывается как:

```python
# a ≡ b (mod k) записывается как:
a % k == b % k

# Или эквивалентно:
(a - b) % k == 0
```

### Пример из задачи:

```python
# Задача: найти подмассив с суммой, кратной k
# Если prefix[i] % k == prefix[j] % k, то:
# prefix[i] ≡ prefix[j] (mod k)
# Значит, сумма подмассива nums[j+1...i] кратна k

if prefix[i] % k == prefix[j] % k:
    # Сумма подмассива от j+1 до i кратна k
    return True
```

## Другие полезные символы

| Символ | Название                | Пример          | Значение                        |
| ------ | ----------------------- | --------------- | ------------------------------- |
| `≡`    | Конгруэнтность          | `a ≡ b (mod k)` | a и b дают одинаковый остаток   |
| `⟺`    | Эквивалентность         | `A ⟺ B`         | A тогда и только тогда, когда B |
| `⇒`    | Импликация              | `A ⇒ B`         | Если A, то B                    |
| `⟹`    | То же (длинная стрелка) | `A ⟹ B`         | Если A, то B                    |
| `∀`    | Для всех                | `∀x`            | Для любого x                    |
| `∃`    | Существует              | `∃x`            | Существует такое x              |
| `∈`    | Принадлежность          | `x ∈ S`         | x принадлежит множеству S       |

## Итог

Символ `≡` — это **математическая нотация** для "сравнимости по модулю". В программировании это просто означает:

```python
a % k == b % k
```

Это мощный инструмент для рассуждений о делимости и остатках, который часто используется в алгоритмах и криптографии.

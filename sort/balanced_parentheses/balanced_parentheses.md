### Описание задачи

Дана строка **A**, состоящая только из символов **'('** и **')'**.

Нужно определить, сбалансированы ли скобки в строке **A**. Если сбалансированы — вернуть **1**, иначе — **0**.

### Ограничения

```
1 <= |A| <= 10^5
```

### Формат ввода/вывода

- **Вход:** строка `A`
- **Выход:** `1`, если скобки сбалансированы, иначе `0`

### Примеры

| Вход | Выход | Пояснение |
|------|-------|-----------|
| `A = "(()())"` | `1` | Скобки сбалансированы |
| `A = "(()"` | `0` | Скобки не сбалансированы |

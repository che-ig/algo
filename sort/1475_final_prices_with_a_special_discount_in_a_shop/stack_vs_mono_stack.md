# Стек vs Монотонный стек: как распознать

## Обычный стек

Используется, когда важна **структура вложенности** или порядок **LIFO** (последним пришёл — первым ушёл).

**Типичные сигналы в условии:**

- Скобки, парные символы
- Отмена последнего действия
- Обработка в обратном порядке
- Вложенные структуры

**Примеры:**

- Валидные скобки `([{}])`
- Вычисление выражений / обратная польская запись
- Минимальный стек

---

## Монотонный стек

Используется, когда для каждого элемента нужно найти **ближайший больший или меньший элемент** слева/справа, либо **границу**, до которой элемент «доминирует».

**Типичные сигналы в условии:**

| Фраза / паттерн                                     | Что ищем                                        |
| --------------------------------------------------- | ----------------------------------------------- |
| «ближайший элемент, который больше/меньше текущего» | Next/Previous Greater/Smaller Element           |
| «сколько дней подряд температура была ниже»         | Насколько элемент «протягивает» в одну сторону  |
| «площадь прямоугольника в гистограмме»              | Границы для каждого столбца                     |
| «сколько воды задержится между столбцами»           | Ближайшие столбцы выше текущего                 |
| «сумма минимумов/максимумов подмассивов»            | Для каждого элемента — границы, где он мин/макс |
| «видимые люди в очереди»                            | Сколько элементов текущий «перекрывает»         |

**Главный принцип:** в стеке элементы всегда упорядочены (возрастают или убывают). Когда новый элемент нарушает порядок — мы **выталкиваем** элементы из стека.

```
Монотонный стек (убывающий):  [9, 7, 5, 3]  ← приходим с элементом 6
Выталкиваем 3, 5 (они < 6), кладём 6:  [9, 7, 6]
```

## Шпаргалка: какой стек нужен

```
Нужно найти СЛЕВА:
  ├─ ближайший МЕНЬШИЙ  →  монотонно ВОЗРАСТАЮЩИЙ стек, идём слева направо
  └─ ближайший БОЛЬШИЙ  →  монотонно УБЫВАЮЩИЙ стек, идём слева направо

Нужно найти СПРАВА:
  ├─ ближайший МЕНЬШИЙ  →  монотонно ВОЗРАСТАЮЩИЙ стек, идём справа налево
  └─ ближайший БОЛЬШИЙ  →  монотонно УБЫВАЮЩИЙ стек, идём справа налево
```

**Задачи ⭐** — это «обязательная классика», с которых стоит начинать, если вы только знакомитесь с монотонным стеком: **739 → 84 → 42 → 907**.

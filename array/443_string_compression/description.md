Эта задача (LeetCode 443. String Compression) решается с помощью классического подхода «два указателя» (Two Pointers).
Главная сложность здесь — записать сжатую строку in-place (прямо в исходный массив) и использовать O(1)O(1)O(1) дополнительной памяти.
Идея решения
Мы будем использовать два указателя:

    read (чтение) — будет бежать по исходному массиву и считать количество подряд идущих одинаковых символов.
    write (запись) — будет указывать на позицию в этом же массиве, куда мы будем перезаписывать сжатые данные.

Поскольку сжатая строка всегда короче или равна по длине исходной (в худшем случае, если нет повторяющихся символов, указатель write никогда не обгонит read), мы можем безопасно перезаписывать массив «на лету», не боясь затереть еще непрочитанные данные.
Код на Python с комментариями

```python

from typing import List

class Solution:
    def compress(self, chars: List[str]) -> int:
        # read - указатель для чтения исходных символов
        # write - указатель для записи сжатых символов
        read = 0
        write = 0

        # Проходим по массиву, пока не прочитаем все символы
        while read < len(chars):
            # Запоминаем текущий символ для подсчета группы
            current_char = chars[read]
            count = 0

            # Считаем длину текущей группы одинаковых символов
            while read < len(chars) and chars[read] == current_char:
                read += 1
                count += 1

            # 1. Записываем сам символ
            chars[write] = current_char
            write += 1

            # 2. Если в группе больше одного символа, записываем её длину
            if count > 1:
                # Если длина >= 10, str(count) вернет строку из нескольких цифр.
                # Мы посимвольно записываем каждую цифру в массив.
                for digit in str(count):
                    chars[write] = digit
                    write += 1

        # По условию нужно вернуть новую длину массива
        return write

# --- Проверка на примерах ---
if __name__ == "__main__":
    sol = Solution()

    chars1 = ["a","a","b","b","c","c","c"]
    print(sol.compress(chars1), chars1)
    # Ожидается: 6, ['a', '2', 'b', '2', 'c', '3']

    chars2 = ["a"]
    print(sol.compress(chars2), chars2)
    # Ожидается: 1, ['a']

    chars3 = ["a","b","b","b","b","b","b","b","b","b","b","b","b"]
    print(sol.compress(chars3), chars3)
    # Ожидается: 4, ['a', 'b', '1', '2']
```

Подробное пояснение алгоритма

    Инициализация: Оба указателя read и write стартуют с индекса 0.
    Поиск группы: Во внешнем цикле мы берем символ chars[read] и во внутреннем цикле двигаем указатель read вправо, пока символы совпадают. Счетчик count фиксирует размер группы.
    Запись символа: Как только группа закончилась, мы записываем current_char по индексу write и сдвигаем write на 1.
    Запись числа: Если count > 1, нам нужно записать само число. Мы конвертируем его в строку (str(count)) и в цикле for записываем каждую цифру отдельно. Это элегантно решает проблему с числами ≥10\ge 10≥10 (например, 12 разобьется на '1' и '2').
    Возврат результата: После обработки всего массива переменная write будет содержать количество записанных символов, то есть новую длину массива.

Анализ сложности

    Временная сложность: O(N)O(N)O(N), где NNN — длина массива chars.
    Каждый элемент массива посещается указателем read ровно один раз. Указатель write также делает не более NNN шагов. Преобразование числа в строку и его посимвольная запись занимают время, пропорциональное количеству цифр (максимум 6 цифр для длины 200020002000), что является константой.
    Пространственная сложность: O(1)O(1)O(1).
    Мы используем только несколько скалярных переменных (read, write, current_char, count). Вся модификация происходит в исходном массиве chars. Временная строка, создаваемая при str(count), имеет максимальную длину 6 символов, что также является константой и не зависит от NNN. Ограничение по памяти строго соблюдено.

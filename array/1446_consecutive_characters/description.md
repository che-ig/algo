Идея решения
Нам нужно найти максимальную длину непрерывной последовательности (подстроки), состоящей из одного и того же символа. Мы можем пройтись по строке слева направо, поддерживая счетчик длины текущей последовательности одинаковых символов:

Если текущий символ совпадает с предыдущим, мы увеличиваем счетчик текущей последовательности на 1.
Если символ отличается от предыдущего, последовательность прерывается, и мы сбрасываем счетчик до 1 (начинаем считать новую последовательность с текущего символа).
На каждом шаге (или при прерывании) мы сравниваем текущий счетчик с глобальным максимумом и обновляем его, если нужно.

Код на Python с комментариями

```python
class Solution:
    def maxPower(self, s: str) -> int:
        # Так как по ограничениям длина строки минимум 1,
        # начальное значение максимума и текущего счетчика равно 1.
        max_power = 1
        current_power = 1

        # Начинаем обход строки со второго символа (индекс 1)
        for i in range(1, len(s)):
            # Если текущий символ совпадает с предыдущим
            if s[i] == s[i - 1]:
                current_power += 1
                # Обновляем глобальный максимум, если текущая последовательность длиннее
                if current_power > max_power:
                    max_power = current_power
            else:
                # Если символ отличается, начинаем новую последовательность
                current_power = 1

        return max_power

# --- Проверка на примерах ---
if __name__ == "__main__":
    sol = Solution()
    print(sol.maxPower("leetcode"))             # Ожидается: 2 ("ee")
    print(sol.maxPower("abbcccddddeeeeedcba"))  # Ожидается: 5 ("eeeee")
```

Подробное пояснение алгоритма

Инициализация: Мы создаем две переменные: max_power (для хранения ответа) и current_power (для подсчета длины текущей группы одинаковых символов). Обе изначально равны 1, так как минимальная длина строки по условиям равна 1, и один символ уже образует последовательность длиной 1.

Итерация: Мы проходим по строке, начиная с индекса 1. На каждом шаге мы сравниваем символ s[i] с предыдущим s[i - 1].
Ветвление:
Совпадение: Если символы равны, мы просто увеличиваем current_power на 1 и проверяем, не превысила ли эта длина наш max_power.
Различие: Если символы не равны, текущая последовательность оборвалась. Мы сбрасываем current_power в 1, чтобы начать отсчет новой группы с текущего символа.
Возврат результата: После завершения цикла в переменной max_power будет храниться максимальная длина найденной последовательности.

Анализ сложности

Временная сложность: O(N)O(N)O(N), где NNN — длина строки s.
Мы совершаем ровно один проход по строке, выполняя константное количество операций (сравнение и инкремент) на каждом символе.
Пространственная сложность: O(1)O(1)O(1).
Мы используем только две целочисленные переменные (max_power и current_power), объем памяти которых не зависит от длины входной строки.

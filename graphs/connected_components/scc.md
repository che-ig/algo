# Что такое SCC и сильная связность

---

## Начнём с простого: что такое "связность"

**Связный граф** — это граф, в котором **из любой вершины можно добраться до любой другой**.

**Пример связного графа:**

```
    A --- B --- C
    |           |
    D --------- E
```

Из любой вершины можно дойти до любой другой. Граф связный.

**Пример несвязного графа:**

```
    A --- B       C --- D
```

Из A нельзя добраться до C. Граф несвязный.

---

## Проблема с ориентированными графами

В **неориентированном** графе всё просто: если есть ребро A—B, можно идти в обе стороны. Связность — бинарное понятие: граф либо связный, либо нет.

Но в **ориентированном** графе рёбра имеют **направление**, и всё становится сложнее.

**Пример:**

```
    A → B → C
```

- Из A можно добраться до B? ✅ Да.
- Из A можно добраться до C? ✅ Да.
- Из C можно добраться до A? ❌ Нет! Стрелки идут только вправо.

Так этот граф связный или нет? **Зависит от того, как определить "связность".**

---

## Три уровня связности в ориентированных графах

### 1. Слабая связность (Weakly Connected)

Если **забыть про направление стрелок** и считать все рёбра двусторонними, граф становится связным.

```
    A → B → C    (ориентированный)
    A — B — C    (если забыть стрелки — связный!)
```

Этот граф **слабо связный**: если игнорировать направления, из любой вершины можно дойти до любой.

### 2. Односторонняя связность (Unilaterally Connected)

Для **любой пары** вершин (u, v) существует путь **хотя бы в одну сторону**: либо из u в v, либо из v в u (или в обе).

```
    A → B → C
```

- A→B ✅, A→C ✅, B→C ✅
- B→A ❌, C→A ❌, C→B ❌
- Но для каждой пары есть путь хотя бы в одну сторону → **односторонне связный**.

### 3. Сильная связность (Strongly Connected) ⭐

Для **любой пары** вершин (u, v) существует путь **в обе стороны**: и из u в v, и из v в u.

```
    A → B
    ↑   ↓
    C ← D
```

- A→B ✅, B→A? B→D→C→A ✅
- A→C? A→B→D→C ✅, C→A ✅
- Все пары достижимы в обе стороны → **сильно связный!**

---

## Формальное определение

> **Ориентированный граф называется сильно связным**, если для **любых двух вершин** u и v существует ориентированный путь из u в v **и** из v в u.

Проще говоря: **ты можешь доехать из любого города в любой другой и вернуться обратно**, следуя только по дорогам с односторонним движением.

---

## Что такое SCC (Strongly Connected Component)?

> **SCC (компонента сильной связности)** — это **максимальное** подмножество вершин ориентированного графа, которое **сильно связно**.

Ключевое слово — **максимальное**. Это значит, что нельзя добавить ни одну вершину извне, не нарушив сильную связность.

---

## Пример из жизни: город с односторонними улицами

Представьте город, где все улицы односторонние:

```
        Центр
       ↗     ↘
   Север       Юг
       ↖     ↙
        Запад

    Пригород → Деревня
```

- **Центр, Север, Юг, Запад** — все улицы между ними образуют кольцо. Из любого района можно доехать до любого другого и вернуться. Это **одна SCC**.
- **Пригород и Деревня** — из Пригорода можно доехать до Деревни, но обратно нельзя. Это **две отдельные SCC**: `{Пригород}` и `{Деревня}`.

**Итого 3 SCC:**

1. `{Центр, Север, Юг, Запад}` — сильно связная компонента
2. `{Пригород}` — тривиальная SCC (одна вершина)
3. `{Деревня}` — тривиальная SCC (одна вершина)

---

## Визуальный пример

```
    A → B → C
    ↑       ↓
    F ← E ← D
              ↓
              G → H
              ↑   ↓
              J ← I
```

**SCC:**

1. `{A, B, C, D, E, F}` — большой цикл, все достижимы друг из друга
2. `{G, H, I, J}` — маленький цикл
3. Если бы была вершина K без циклов — `{K}` была бы отдельной SCC

---

## Почему "компонента", а не просто "граф"?

Потому что весь граф **целиком** может не быть сильно связным. SCC — это **куски** графа, внутри которых сильная связность есть.

**Аналогия:** Представьте архипелаг. Весь архипелаг — это граф. Каждый остров — это SCC. Внутри острова вы можете дойти из любой точки в любую (сильная связность). Но между островами — только мосты в одну сторону (или вообще нет мостов).

---

## Тривиальные случаи

| Ситуация                                                           | SCC                                          |
| ------------------------------------------------------------------ | -------------------------------------------- |
| **Одна вершина без рёбер**                                         | `{вершина}` — тривиальная SCC                |
| **Дерево** (ориентированное)                                       | Каждая вершина — отдельная SCC               |
| **Цикл**                                                           | Весь цикл — одна SCC                         |
| **Полный ориентированный граф** (все пары соединены в обе стороны) | Весь граф — одна SCC                         |
| **DAG** (ориентированный ациклический граф)                        | Каждая вершина — отдельная SCC (циклов нет!) |

---

## Почему SCC важна?

### 1. Сжатие графа

Если "схлопнуть" каждую SCC в одну вершину, получится **DAG** (граф без циклов). Это называется **конденсацией графа**.

```
До сжатия:                    После сжатия:
A → B → C                     [ABC] → [GH]
↑       ↓
F ← E ← D
              ↓
              G → H
              ↑   ↓
              J ← I
```

DAG намного проще анализировать: можно делать топологическую сортировку, искать критические пути и т.д.

### 2. Реальные применения

| Область       | Что значит SCC                                              |
| ------------- | ----------------------------------------------------------- |
| **Веб-граф**  | Группы сайтов, которые ссылаются друг на друга (линк-фермы) |
| **Соцсети**   | Группы людей, которые взаимно подписаны друг на друга       |
| **Биология**  | Группы генов/белков, которые взаимно регулируют друг друга  |
| **Программы** | Циклические зависимости между модулями (bad practice!)      |
| **Финансы**   | Группы компаний с перекрёстным владением                    |

---

## Итог

| Термин             | Значение                                                      |
| ------------------ | ------------------------------------------------------------- |
| **Связный граф**   | Из любой вершины можно дойти до любой (неориентированный)     |
| **Слабо связный**  | Связный, если забыть направления рёбер                        |
| **Сильно связный** | Из любой вершины можно дойти до любой **и вернуться обратно** |
| **SCC**            | Максимальная группа вершин, внутри которой сильная связность  |
| **Конденсация**    | Сжатие SCC в вершины → получается DAG                         |

**Простыми словами:** SCC — это "клубы взаимности" в графе. Внутри клуба все могут добраться друг до друга и вернуться. Между клубами — только односторонние дороги.

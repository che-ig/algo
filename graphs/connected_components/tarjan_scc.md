# Алгоритм Тарьяна

У Роберта Тарьяна несколько известных алгоритмов (поиск мостов, точек сочленения, LCA), но самый классический — это **алгоритм поиска компонент сильной связности (Strongly Connected Components, SCC)** в ориентированном графе. О нём и поговорим.

---

## Что такое компонента сильной связности?

В **ориентированном** графе SCC — это максимальное множество вершин, в котором **из любой вершины можно добраться до любой другой** по направленным рёбрам.

**Пример:**

```
    A → B → C
    ↑       ↓
    D ← E ← F
        ↓
        G
```

Здесь:

- `{A, B, C, D, E, F}` — одна SCC (из любой можно добраться до любой).
- `{G}` — отдельная SCC (из неё никуда не выйти, и в неё можно попасть только из E).

---

## Идея алгоритма

Алгоритм Тарьяна делает **один проход DFS** и использует два ключевых понятия:

1. **`index[v]`** — порядок посещения вершины (когда мы её впервые увидели).
2. **`lowlink[v]`** — минимальный `index`, достижимый из поддерева `v` через back-edge (ребро в уже посещённую вершину в текущем стеке DFS).

**Ключевая интуиция:**

- Если `lowlink[v] == index[v]`, то `v` — **корень SCC**. Все вершины, которые были добавлены в стек после `v` и имеют `lowlink >= index[v]`, принадлежат той же SCC.
- Мы выгребаем их из стека — это и есть одна SCC.

**Связь с цветами вершин:** Помните трёхцветную систему (белый/серый/чёрный)? Здесь мы используем её неявно:

- Вершины в стеке — это "серые" (в процессе обработки).
- `lowlink` обновляется только при переходе в "серую" вершину (back-edge).
- Когда вершина становится "чёрной" (полностью обработана), она либо стала корнем SCC, либо уже принадлежит SCC своего родителя.

## Реализация на Python

```python
def tarjan_scc(graph):
    """
    Алгоритм Тарьяна для поиска компонент сильной связности (SCC).

    Args:
        graph: dict, список смежности ориентированного графа.
               Пример: {'A': ['B'], 'B': ['C', 'A'], 'C': []}

    Returns:
        list of lists: каждая компонента — список вершин.
    """

    index_counter = [0]  # Счётчик index (используем список для изменяемости в замыкании)
    stack = []           # Стек вершин в текущем пути DFS
    lowlink = {}         # lowlink[v] = минимальный index, достижимый из v
    index = {}           # index[v] = порядок посещения v
    on_stack = set()     # Множество вершин, находящихся в стеке
    sccs = []            # Результат: список SCC

    def strongconnect(v):
        # Шаг 1: Присваиваем index и lowlink
        index[v] = index_counter[0]
        lowlink[v] = index_counter[0]
        index_counter[0] += 1
        stack.append(v)
        on_stack.add(v)

        # Шаг 2: Обходим соседей
        for w in graph.get(v, []):
            if w not in index:
                # Сосед ещё не посещён — рекурсивный вызов
                strongconnect(w)
                lowlink[v] = min(lowlink[v], lowlink[w])
            elif w in on_stack:
                # Сосед в стеке (серый) — это back-edge, обновляем lowlink
                lowlink[v] = min(lowlink[v], index[w])

        # Шаг 3: Если v — корень SCC, выгребаем SCC из стека
        if lowlink[v] == index[v]:
            scc = []
            while True:
                w = stack.pop()
                on_stack.remove(w)
                scc.append(w)
                if w == v:
                    break
            sccs.append(scc)

    # Шаг 4: Запускаем DFS от каждой непосещённой вершины
    for v in graph:
        if v not in index:
            strongconnect(v)

    return sccs
```

## Пример использования

```python
if __name__ == "__main__":
    # Граф с двумя SCC
    # SCC 1: {A, B, C, D, E, F}
    # SCC 2: {G}
    graph = {
        'A': ['B'],
        'B': ['C'],
        'C': ['D'],
        'D': ['E'],
        'E': ['F', 'G'],
        'F': ['A'],  # ← Цикл A→B→C→D→E→F→A
        'G': []
    }

    sccs = tarjan_scc(graph)

    print("Компоненты сильной связности:")
    for i, scc in enumerate(sccs, 1):
        print(f"  SCC {i}: {scc}")
```

**Вывод:**

```
Компоненты сильной связности:
  SCC 1: ['G']
  SCC 2: ['F', 'E', 'D', 'C', 'B', 'A']
```

## Пошаговая визуализация

Давайте посмотрим, как алгоритм работает на простом графе:

```
    A → B
    ↑   ↓
    D ← C
```

```
Шаг 1: strongconnect(A)
  index[A] = 0, lowlink[A] = 0
  stack = [A], on_stack = {A}

  Сосед B: не посещён → strongconnect(B)

Шаг 2: strongconnect(B)
  index[B] = 1, lowlink[B] = 1
  stack = [A, B], on_stack = {A, B}

  Сосед C: не посещён → strongconnect(C)

Шаг 3: strongconnect(C)
  index[C] = 2, lowlink[C] = 2
  stack = [A, B, C], on_stack = {A, B, C}

  Сосед D: не посещён → strongconnect(D)

Шаг 4: strongconnect(D)
  index[D] = 3, lowlink[D] = 3
  stack = [A, B, C, D], on_stack = {A, B, C, D}

  Сосед A: посещён И в стеке! → lowlink[D] = min(3, index[A]) = min(3, 0) = 0

  lowlink[D] (0) != index[D] (3) → D не корень SCC

Шаг 5: Возврат в C
  lowlink[C] = min(2, lowlink[D]) = min(2, 0) = 0
  lowlink[C] (0) != index[C] (2) → C не корень SCC

Шаг 6: Возврат в B
  lowlink[B] = min(1, lowlink[C]) = min(1, 0) = 0
  lowlink[B] (0) != index[B] (1) → B не корень SCC

Шаг 7: Возврат в A
  lowlink[A] = min(0, lowlink[B]) = min(0, 0) = 0
  lowlink[A] (0) == index[A] (0) → A КОРЕНЬ SCC!

  Выгребаем из стека: D, C, B, A → SCC = [D, C, B, A]

Результат: [[D, C, B, A]]
```

## Сложность

| Параметр   | Значение                                     |
| ---------- | -------------------------------------------- |
| **Время**  | $O(V + E)$ — один проход DFS                 |
| **Память** | $O(V)$ — для стека, lowlink, index, on_stack |

Это **оптимально** — мы посещаем каждую вершину и каждое ребро ровно один раз.

---

## Где применяется

1. **Анализ зависимостей:** Определение циклических зависимостей в модулях, пакетах, задачах сборки.
2. **Социальные сети:** Поиск групп пользователей, которые взаимно связаны (кланы, сообщества).
3. **Компиляторы:** Анализ потока данных, оптимизация циклов.
4. **Биоинформатика:** Анализ регуляторных сетей (какие гены взаимно влияют друг на друга).
5. **Сжатие графов:** После нахождения SCC граф можно "сжать" в DAG (каждая SCC → одна вершина), что упрощает дальнейший анализ.

## Сравнение с алгоритмом Косарайю

Есть ещё один известный алгоритм для SCC — **Косарайю**. Он использует **два прохода DFS**:

1. Первый проход: находим порядок завершения вершин.
2. Второй проход: обходим граф с обращёнными рёбрами в порядке убывания времени завершения.

| Аспект                        | Тарьян                | Косарайю                                  |
| ----------------------------- | --------------------- | ----------------------------------------- |
| **Количество проходов**       | 1                     | 2                                         |
| **Нужно ли обращать граф?**   | Нет                   | Да                                        |
| **Сложность**                 | $O(V + E)$            | $O(V + E)$                                |
| **Проще для понимания**       | Сложнее               | Проще                                     |
| **Эффективность на практике** | Быстрее (один проход) | Медленнее (два прохода + обращение графа) |

**Вывод:** Алгоритм Тарьяна более эффективен (один проход, не нужно строить обратный граф), но сложнее для понимания. Косарайю проще объяснить, но работает медленнее.

---

## Итог

Алгоритм Тарьяна для SCC — это элегантный и эффективный способ найти все компоненты сильной связности в ориентированном графе за один проход DFS. Он использует идею `lowlink` для отслеживания "самого раннего" достижимого предка и определяет корень SCC по равенству `lowlink == index`.

**Ключевые моменты:**

- Один проход DFS — $O(V + E)$.
- Использует стек и множества для отслеживания "серых" вершин.
- Корень SCC определяется по `lowlink[v] == index[v]`.
- Оптимален по времени и памяти.

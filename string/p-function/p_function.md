**Префикс-функция** — это важное понятие в алгоритмах обработки строк. Она лежит в основе знаменитого алгоритма Кнута-Морриса-Пратта (КМП) для поиска подстроки в строке.

### Определение
Для строки $s$ длины $n$ **префикс-функцией** называется массив $\pi$ длины $n$, где $\pi[i]$ — это длина **наибольшего собственного префикса** подстроки $s[0 \dots i]$, который одновременно является её суффиксом.

*   *Собственный префикс* — это префикс, который не совпадает со всей строкой целиком (его длина строго меньше $i+1$).
*   Следовательно, $\pi[0]$ всегда равно $0$.

### Пример
Рассмотрим строку `s = "abcabcd"`.
Посчитаем $\pi$ для каждого префикса:
*   `a` -> 0
*   `ab` -> 0
*   `abc` -> 0
*   `abca` -> **1** (префикс `a` = суффикс `a`)
*   `abcab` -> **2** (префикс `ab` = суффикс `ab`)
*   `abcabc` -> **3** (префикс `abc` = суффикс `abc`)
*   `abcabcd` -> 0

Итоговый массив: **$\pi = [0, 0, 0, 1, 2, 3, 0]$**

---

### Наивный алгоритм ($O(n^3)$ или $O(n^2)$)
Самый очевидный способ — для каждой позиции $i$ перебирать все возможные длины $l$ (от $i$ до $1$) и проверять, совпадает ли префикс длины $l$ с суффиксом длины $l$. Это работает слишком долго для больших строк.

---

### Эффективный алгоритм ($O(n)$)
Главная хитрость алгоритма заключается в том, что **мы используем уже посчитанные значения $\pi$, чтобы избежать лишних сравнений**.

#### Идея оптимизации
Пусть мы считаем $\pi[i]$ и уже знаем $\pi[i-1] = k$.
Это означает, что фрагмент строки $s[0 \dots k-1]$ в точности равен фрагменту $s[i-k \dots i-1]$.

Чтобы продолжить совпадение, нам нужно проверить: **равен ли $s[k]$ символу $s[i]$?**
1.  **Если $s[k] == s[i]$**: Отлично! Мы просто расширяем наш префикс. $\pi[i] = k + 1$.
2.  **Если $s[k] \neq s[i]$**: Совпадение прервалось. Нам нужно найти *следующий по длине* префикс, который является суффиксом для $s[0 \dots i-1]$.
    *   По определению, длина следующего по убыванию такого префикса равна $\pi[k-1]$.
    *   Мы "откатываем" значение $k$ к $\pi[k-1]$ и снова пытаемся сравнить $s[k_{new}]$ с $s[i]$.
    *   Мы повторяем этот откат, пока $k > 0$. Если $k$ стало равно $0$, мы просто сравниваем $s[0]$ с $s[i]$.

#### Код на Python
```python
def prefix_function(s: str) -> list[int]:
    n = len(s)
    pi = [0] * n
    
    for i in range(1, n):
        j = pi[i - 1]  # Длина текущего совпадающего префикса/суффикса
        
        # Откатываемся назад, пока можем и пока символы не совпадают
        while j > 0 and s[i] != s[j]:
            j = pi[j - 1]
            
        # Если символы совпали, увеличиваем длину префикса
        if s[i] == s[j]:
            j += 1
            
        pi[i] = j
        
    return pi
```

#### Доказательство сложности $O(n)$
На первый взгляд кажется, что внутри цикла `for` есть цикл `while`, и сложность $O(n^2)$. Но это не так.
*   Переменная `j` увеличивается **не более чем на 1** за каждую итерацию внешнего цикла `for`. Значит, за все $n$ итераций `j` увеличится суммарно не более $n$ раз.
*   Цикл `while` только **уменьшает** значение `j`.
*   Поскольку `j` не может быть отрицательным, количество уменьшений (итераций `while`) не может превышать количество увеличений.
*   Следовательно, суммарное количество итераций `while` за всю работу алгоритма $\le n$.
*   **Итоговая асимптотика:** $O(n)$ по времени и $O(n)$ по памяти.

### Где это применяется?

1.  **Алгоритм Кнута-Морриса-Пратта (KMP)**
    Чтобы найти все вхождения подстроки `pattern` в текст `text`, мы склеиваем их через специальный разделитель (которого нет ни там, ни там, например, `#`):
    `s = pattern + "#" + text`
    Считаем префикс-функцию для `s`. Если в какой-то позиции $i$ значение $\pi[i]$ равно длине `pattern`, значит, мы нашли полное вхождение подстроки в текст!
    *Сложность поиска:* $O(|pattern| + |text|)$.

2.  **Поиск периода строки**
    Префикс-функция позволяет найти минимальный размер блока, многократным повторением которого образована строка.
    Если длина строки $n$ делится на $(n - \pi[n-1])$, то строка имеет период длиной $n - \pi[n-1]$.
    *Пример:* `abcabcabc` (длина 9). $\pi[8] = 6$. Период = $9 - 6 = 3$ (блок `abc`).

3.  **Подсчет количества вхождений каждого префикса**
    С помощью префикс-функции и динамического программирования можно за $O(n)$ посчитать, сколько раз каждый префикс строки встречается в ней самой в виде подстроки.

4.  **Сжатие строки (поиск наименьшей сжимающей строки)**
    Задача: найти строку минимальной длины, из которой повторениями можно получить исходную. Решается через проверку делимости $n$ на $(n - \pi[n-1])$, как описано в пункте 2.

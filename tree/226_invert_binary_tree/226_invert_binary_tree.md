Easy

Given the `root` of a binary tree, invert the tree, and return _its root_.

**Example 1:**

![](./226_invert_binary_tree_images/2fc4466f5d108a51e951edbda0741714_MD5.jpg)

**Input:** root = [4,2,7,1,3,6,9]
**Output:** [4,7,2,9,6,3,1]

**Example 2:**

![](./226_invert_binary_tree_images/1f062518c38304e5b01ad0941bc55e98_MD5.jpg)

**Input:** root = [2,1,3]
**Output:** [2,3,1]

**Example 3:**

**Input:** root = []
**Output:** []

**Constraints:**

- The number of nodes in the tree is in the range `[0, 100]`.
- `-100 <= Node.val <= 100`

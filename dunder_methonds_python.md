Магические методы (или **dunder-методы**, от _double underscore_ — двойное подчеркивание) в Python 3.12 позволяют вашим объектам вести себя как встроенные типы данных: реагировать на операторы, вызываться как функции, итерироваться и т.д.

Чтобы не утонуть в сотне методов, я разбил их на логические категории. Для каждой категории и метода я добавил **мнемонику** — ассоциацию, которая поможет вам вспомнить их назначение на собеседовании или при написании кода.

---

### 1. Жизненный цикл и базовое поведение

Эти методы определяют, как объект создается, уничтожается и взаимодействует с базовыми операциями.

- **`__init__(self, ...)`**
  - **Что делает:** Инициализирует состояние уже созданного объекта.
  - **Мнемоника:** **Init** = **И**нициализация. «Я родился и настроил свои параметры».
- **`__del__(self)`**
  - **Что делает:** Вызывается при уничтожении объекта (сборщиком мусора).
  - **Мнемоника:** **Del** = **Д**олой / **Del**ete. «Меня стирают из памяти, пора прощаться».
- **`__call__(self, ...)`**
  - **Что делает:** Позволяет вызывать экземпляр класса как функцию: `obj()`.
  - **Мнемоника:** **Call** = Звонок. «Позвони мне, позвони» (объект отвечает на звонок, как функция).
- **`__bool__(self)`**
  - **Что делает:** Определяет поведение объекта в логическом контексте (`if obj:`, `bool(obj)`).
  - **Мнемоника:** **Bool** = **Б**одрый (True) или **Б**ез сил (False). «Этот объект живой или нет?».

---

### 2. Строковое представление

Как объект выглядит, когда его превращают в текст.

- **`__str__(self)`**
  - **Что делает:** Возвращает понятное человеку строковое представление (вызывается через `print()` и `str()`).
  - **Мнемоника:** **Str** = **Стр**ока для **Ст**раны (для обычных пользователей). «Читабельно для людей».
- **`__repr__(self)`**
  - **Что делает:** Возвращает строковое представление для разработчиков (в идеале — код для создания объекта). Вызывается в REPL и при выводе списков.
  - **Мнемоника:** **Repr** = **Р**азработчик **П**ишет (код). Или **Реп**утация перед профессионалами. «Покажи мне код, чтобы я его понял».
- **`__format__(self, format_spec)`**
  - **Что делает:** Управляет тем, как объект форматируется внутри f-строк или `format()`.
  - **Мнемоника:** **Format** = **Ф**ормат **А**квариума. «Как красиво упаковать рыбку (объект) для витрины».

---

### 3. Сравнение и хэширование

Позволяют объектам сравниваться друг с другом и использоваться в качестве ключей словарей.

- **`__eq__`, `__ne__`** (==, !=)
  - **Что делает:** Проверка на равенство и неравенство.
  - **Мнемоника:** **Eq** = **Эк**вивалентно. **Ne** = **Н**е **Э**квивалентно.
- **`__lt__`, `__le__`, `__gt__`, `__ge__`** (<, <=, >, >=)
  - **Что делает:** Меньше, меньше/равно, больше, больше/равно.
  - **Мнемоника:** Запоминаем английские корни: **lt** = **l**ess **t**han (меньше), **gt** = **g**reater **t**han (больше). _Лайфхак:_ **l** = **л**евее (меньше), **g** = **г**лавнее (больше).
- **`__hash__(self)`**
  - **Что делает:** Возвращает хэш-целое число. Нужно, чтобы объект мог быть ключом в `dict` или элементом `set`.
  - **Мнемоника:** **Hash** = **Х**эш **А**йди **Ш**ифр. «Уникальный паспорт объекта для словаря».

### 4. Доступ к атрибутам

Самая частая причина багов, если путать эти методы!

- **`__getattr__(self, name)`**
  - **Что делает:** Вызывается **ТОЛЬКО** если атрибут **НЕ БЫЛ НАЙДЕН** обычным способом.
  - **Мнемоника:** **Get** **Attr** -> «Дай атрибут, а то **Гав**!» (срабатывает как fallback, когда атрибута нет).
- **`__getattribute__(self, name)`**
  - **Что делает:** Вызывается при **ЛЮБОМ** обращении к атрибуту, даже если он существует.
  - **Мнемоника:** **Get** **Attribute** -> «Дай **А**трибут **Т**очно!» (перехватывает всё на корню, работает всегда).
- **`__setattr__(self, name, value)`**
  - **Что делает:** Вызывается при присваивании значения атрибуту (`obj.x = 1`).
  - **Мнемоника:** **Set** -> **С**охранить **Е**го **Т**уда.
- **`__delattr__(self, name)`**
  - **Что делает:** Вызывается при удалении атрибута (`del obj.x`).
  - **Мнемоника:** **Del** -> **Д**олой **Е**го **Т**уда.
- **`__dir__(self)`**
  - **Что делает:** Возвращает список атрибутов объекта (работает при вызове `dir(obj)`).
  - **Мнемоника:** **Dir** = **Дир**ектория. «Покажи содержимое папки (объекта)».

---

### 5. Контейнеры, коллекции и итерации

Делают из вашего объекта список, словарь или итератор.

- **`__len__(self)`**
  - **Что делает:** Возвращает длину объекта (`len(obj)`).
  - **Мнемоника:** **Len** = **Л**юбая **Е**диница **Н** (длина).
- **`__getitem__(self, key)`**
  - **Что делает:** Получение элемента по индексу или ключу (`obj[key]`).
  - **Мнемоника:** **Get** **Item** = «Возьми **Айтем** (предмет) из сундука».
- **`__setitem__(self, key, value)`**
  - **Что делает:** Установка элемента (`obj[key] = value`).
  - **Мнемоника:** **Set** **Item** = «Положи **Айтем** в сундук».
- **`__delitem__(self, key)`**
  - **Что делает:** Удаление элемента (`del obj[key]`).
  - **Мнемоника:** **Del** **Item** = «Выкинь **Айтем** из сундука».
- **`__contains__(self, item)`**
  - **Что делает:** Реализует оператор `in` (`item in obj`).
  - **Мнемоника:** **Contains** = **Кон**тейнер **Т**аит (содержит) в себе.
- **`__missing__(self, key)`**
  - **Что делает:** Специальный метод для словарей. Вызывается, если ключ не найден (используется в `collections.defaultdict`).
  - **Мнемоника:** **Missing** = «Чего не **хватает** (missing)? Дай значение по умолчанию».
- **`__iter__(self)`**
  - **Что делает:** Возвращает итератор для объекта (вызывается в `for` или `iter()`).
  - **Мнемоника:** **Iter** = **И**терация **Т**уда-**Е**р**Р** (шагать по объекту).
- **`__next__(self)`**
  - **Что делает:** Возвращает следующий элемент итератора (вызывается в `next()`).
  - **Мнемоника:** **Next** = **Не**кст (следующий). «Давай некст!».

### 6. Математика и операторы

Превращают объект в число или позволяют складывать/умножать объекты.

**Базовая арифметика:**

- `__add__`, `__sub__`, `__mul__`, `__truediv__`, `__floordiv__`, `__mod__`, `__pow__` (+, -, \*, /, //, %, \*\*)
  - **Мнемоника:** Это просто английские слова: **Add** (плюс), **Sub**tract (минус), **Mul**tiply (умножить), **Div**ide (делить), **Mod**ulo (остаток), **Pow**er (степень).

**Отраженная (обратная) арифметика:**

- `__radd__`, `__rsub__`, `__rmul__` и т.д.
  - **Что делает:** Вызывается, если **левый** операнд не поддерживает операцию, и объект находится **справа** (например, `5 + obj`).
  - **Мнемоника:** **R** = **R**everse (обратный) или **R**ight (правый). «Если я справа, используй R-метод».

**Арифметика на месте (in-place):**

- `__iadd__`, `__isub__`, `__imul__` и т.д. (+=, -=, \*=)
  - **Что делает:** Изменяет сам объект, а не создает новый.
  - **Мнемоника:** **I** = **I**n-place (на месте) или **I**ncrement (изменить себя). «Измени **И**знутри, не создавая нового».

**Унарные операторы:**

- `__neg__` (-obj), `__pos__` (+obj), `__abs__` (abs(obj)), `__invert__` (~obj).
  - **Мнемоника:** **Neg** = Негатив (минус), **Pos** = Позитив (плюс), **Abs** = Абсолют (модуль), **Invert** = Инвертировать (битовое НЕ).

---

### 7. Преобразование типов

Позволяют объекту превращаться во встроенные типы данных.

- **`__int__`, `__float__`, `__complex__`**
  - **Что делает:** Преобразование в `int()`, `float()`, `complex()`.
  - **Мнемоника:** Просто названия встроенных функций.
- **`__round__`, `__trunc__`, `__floor__`, `__ceil__`**
  - **Что делает:** Округление (`round()`), отсечение дробной части (`math.trunc()`), округление вниз (`math.floor()`), округление вверх (`math.ceil()`).
  - **Мнемоника:** **Trunc** = **Тр**унить (отрубить хвост). **Floor** = **Фл**ор (пол) — вниз. **Ceil** = **С**и**л**инг (потолок) — вверх.
- **`__index__(self)`**
  - **Что делает:** Преобразует объект в целое число для использования в срезах (`obj[my_obj:my_obj]`) или функциях `bin()`, `hex()`, `oct()`.
  - **Мнемоника:** **Index** = Индекс. «Преврати меня в индекс массива».

---

### 8. Контекстные менеджеры и асинхронность

Для работы с конструкцией `with` и `async/await`.

- **`__enter__(self)` и `__exit__(self, ...)`**
  - **Что делает:** Определяют действия при входе в блок `with` и выходе из него (даже при исключениях).
  - **Мнемоника:** **Enter** = Войти (в `with`). **Exit** = Выйти (из `with`). «Вошел в комнату и вышел».
- **`__aenter__(self)` и `__aexit__(self, ...)`**
  - **Что делает:** Асинхронные аналоги для `async with`.
  - **Мнемоника:** Буква **A** = **A**sync. «**А**синхронно вошел и вышел».
- **`__aiter__(self)` и `__anext__(self)`**
  - **Что делает:** Асинхронные итераторы (для `async for`).
  - **Мнемоника:** Буква **A** = **A**sync. «**А**синхронно итерируемся».

---

### 💡 Лайфхак для запоминания на практике:

Если вы забыли, как называется метод, вспомните **оператор или функцию**, которую вы хотите переопределить, и переведите её на английский:

- Хотите переопределить `len()`? -> Длина -> Length -> `__len__`.
- Хотите переопределить `+`? -> Сложение -> Add -> `__add__`.
- Хотите переопределить `in`? -> Содержит -> Contains -> `__contains__`.
- Хотите переопределить `str()`? -> Строка -> String -> `__str__`.

В Python 3.12 не появилось новых _базовых_ магических методов для экземпляров (ядро было стабилизировано в версиях 3.5-3.8), поэтому этот список полностью покрывает все актуальные возможности языка!
